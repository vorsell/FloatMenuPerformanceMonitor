# Float Menu Performance Monitor

A RimWorld 1.6 developer tool for locating map right-click-menu performance hotspots. It measures float-menu providers and WorkGiver checks, writes sampled results to `Player.log`, and can register dedicated profiling entries with Dubs Performance Analyzer when available.

This is a diagnostic tool and adds some profiling overhead; disable it before final FPS comparisons.
